Buku Panduan Penggunaan Sistem Manajemen Servis

✅ Self-Service ✅ Live Tracking ✅ Auto WhatsApp ✅ Cetak Nota

Selamat datang di sistem manajemen servis masa depan! Aplikasi ini dirancang khusus untuk mempermudah Anda dalam mencatat, melacak, dan memberi informasi kepada pelanggan secara otomatis.

📱 Bagian 1: Panduan Untuk Pelanggan

Aplikasi ini sangat memanjakan pelanggan. Mereka tidak perlu lagi antre panjang atau terus-menerus bertanya lewat WA tentang status perbaikan HP mereka.

📝 1. Pendaftaran Servis Mandiri (Self-Service)

Pelanggan yang datang ke toko (atau dari rumah) cukup membuka website Anda, lalu:
  1. Klik menu utama berwarna ungu "Daftar Service".
  2. Isi form singkat: Nama, No. WhatsApp, Merek/Tipe HP, dan Keluhan kerusakannya.
  3. Setelah klik "Daftar", layar akan langsung memunculkan ID Servis.
  4. Pelanggan cukup menyerahkan HP ke kasir sambil menyebutkan ID tersebut. Selesai!

🔍 2. Melacak Status Perbaikan Real-Time

Untuk mengetahui apakah perangkat sudah selesai diperbaiki, pelanggan cukup:
  1. Buka website dan klik menu "Lacak Servis".
  2. Masukkan ID Servis yang mereka dapatkan saat mendaftar.
  3. Layar akan menampilkan status terkini perangkat mereka.

💻 Bagian 2: Panduan Untuk Admin / Teknisi

Ini adalah area dapur Anda. Di sini Anda mengatur semua pekerjaan, mencatat biaya, dan mencetak nota. Semua data pendaftaran pelanggan akan otomatis masuk ke sini.

🔐 1. Cara Masuk (Login)

  1. Di halaman utama pelanggan, gulir ke paling bawah.
  2. Klik tombol kecil bertuliskan "🔐 Admin Portal".
  3. Masukkan kata sandi rahasia toko Anda untuk masuk ke Dashboard Pusat.

🖥️ 2. Pengenalan Layar Dashboard Admin

Setelah berhasil masuk, Anda akan melihat layar Daftar Antrean lengkap dengan berbagai petunjuk tombol seperti gambar di bawah ini:

Berikut adalah penjelasan fungsi-fungsi yang ada di layar berdasarkan gambar petunjuk di atas:

  • Pengaturan Aplikasi (Ikon Gir ⚙️): Digunakan untuk mengakses setelan profil dan konfigurasi sistem admin.
  • Keluar (Ikon Pintu 🚪): Untuk logout dengan aman dari panel admin agar data Anda tetap terlindungi.
  • Tombol ➕ Baru: Digunakan untuk menambahkan tiket servis baru secara manual apabila pelanggan mendaftar langsung lewat Anda (offline).
  • Tombol Laporan 📊: Membuka ringkasan, riwayat, dan statistik keuangan atau pengerjaan seluruh servis yang sudah selesai.
  • Kolom Cari 🔍: Membantu Anda menemukan data dengan cepat cukup dengan mengetikkan ID Servis, Nama Pelanggan, atau Nomor WA.
  • Filter Status: Memudahkan Anda menyaring daftar agar hanya menampilkan perangkat berdasarkan proses yang sedang berjalan (Semua, Antrean, Dikerjakan, Selesai).

📋 3. Membaca Kartu Tiket Servis

Setiap perangkat pelanggan ditampilkan dalam bentuk kotak (kartu) yang memuat informasi ringkas namun lengkap. Berikut adalah panduan membaca informasi pada kartu servis:

  • Kode Tiket: Nomor identitas unik untuk servis ini (contoh: SRV-823380).
  • Status Saat Ini: Posisi proses perbaikan saat ini (Antrean, Dikerjakan, Selesai, Diambil).
  • Tipe Perangkat: Merek dan tipe laptop/HP yang sedang diservis.
  • Keluhan Pelanggan: Detail kerusakan atau keluhan yang dialami perangkat.
  • Nama Pelanggan: Nama pemilik perangkat yang terdaftar.
  • No. WhatsApp: Kontak pelanggan untuk pengiriman notifikasi atau WA.
  • Tombol Aksi (Ikon Roket 🚀): Klik untuk mengubah status, mengisi rincian biaya, atau mencetak nota!

✏️ 4. Update Status & Rincian Biaya

Setelah mengeklik tombol Ikon Roket 🚀 pada kartu pelanggan, akan muncul jendela pop-up untuk memperbarui status pekerjaan dan memasukkan rincian tagihan:

Berikut adalah penjelasan lengkap fitur di dalam layar Update Status & Biaya:

  • Kode Tiket: Nomor identitas unik untuk servis ini.
  • Status Pengerjaan: Klik kolom ini untuk mengubah progres servis pelanggan (pilih: Antrean, Sedang Dikerjakan, Selesai, atau Diambil).
  • + Tambah Rincian: Klik tombol teks ini untuk menambahkan baris kosong baru apabila ada beberapa suku cadang yang diganti sekaligus.
  • Jasa & Sparepart: Tulis nama perbaikan/suku cadang beserta biayanya di sini.
  • Hapus Baris (Tanda Silang ❌): Klik tombol silang merah untuk menghapus baris rincian ini.
  • Total Otomatis: Jumlah biaya akan terhitung otomatis dari seluruh rincian di atas.
  • Hapus Tiket (Ikon Tong Sampah 🗑️): Klik untuk menghapus seluruh data servis ini.
  • Batal / Simpan: Klik 'Simpan' untuk memperbarui data, atau 'Batal' untuk kembali.

💬 5. Integrasi WhatsApp (Notifikasi Otomatis)

Setelah perangkat diperbaiki, Anda bisa mengabari pelanggan tanpa perlu mengetik manual:

  1. Ubah Status Pengerjaan menjadi Selesai melalui form di atas, lalu klik Simpan.
  2. Pada kartu pelanggan di halaman depan, akan muncul ikon WhatsApp (Warna Hijau).
  3. Klik ikon tersebut. Sistem akan otomatis membuka WhatsApp web/aplikasi dengan pesan tagihan yang sudah terketik rapi. Anda tinggal klik kirim!

🧾 Bagian 3: Panduan Cetak Nota & Transaksi

Gunakan bagian ini untuk mendokumentasikan tata cara cetak nota dan penyelesaian transaksi keuangan pelanggan Anda.

🖨️ 1. Mencetak Nota Resmi (Struk)

Saat pelanggan datang untuk mengambil perangkat dan melakukan pembayaran:
  1. Ubah status pengerjaan di sistem menjadi Diambil.
  2. Akan muncul Ikon Printer 🖨️ di sebelah data pelanggan tersebut.
  3. Klik ikon Printer untuk membuka halaman pratinjau nota (invoice) cantik berlogo Poer Electro Servis.
  4. Tekan tombol cetak di komputer/HP Anda (atau Ctrl + P) untuk menghubungkannya ke printer struk atau menyimpannya sebagai file PDF.
  5. Berikan cetakan nota fisik tersebut bersama perangkat kepada pelanggan sebagai bukti garansi/pembayaran resmi.
